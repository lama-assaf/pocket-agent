# r3to.os 6.6.0

## Highlights

- **Per-client GitHub tokens.** Each client can now carry its own GitHub token (The Brain → sync bar → key button), used for every sync path — pull/publish, live sync, auto-pull, and join. Falls back to the default Settings → GitHub token per client; stored encrypted, never included in setup links or synced repos.
- **Zilliqa brand pack.** The private `Zilliqa/zilliqa-brand-plugin` repo is now a marketplace pack (design lane): the `zilliqa-brand` and `zilliqa-app-ui` skills auto-update from GitHub, authenticating with the zilliqa client's token, with a bundled seed copy for offline/first-run. Pack sync in general now supports private repos via authenticated GitHub fetches.
- **Per-session isolation.** Concurrent sessions no longer share state they shouldn't: each session can override the agent model independently, browser automation managers are per-session (with all-session teardown on quit and CDP reconnect on wake), and coder mode defaults to a per-session workspace directory with a visible warning when two active coder sessions share one.
- Subagent status tracking is keyed by tool call, so an unrelated tool finishing can no longer be mistaken for a subagent completing.
- Background live-sync no longer error-toasts clients that simply have no token configured yet.

## macOS artifact

The Apple Silicon DMG is named `r3to.os-6.6.0-arm64.dmg`. Local unsigned builds are for testing and require right-clicking the app and choosing **Open**; public distribution should use Developer ID signing and Apple notarization.
