# r3to.os 6.5.3

## Highlights

- Renamed the user-facing desktop product, menus, windows, documentation, and installers from the previous name to **r3to.os**.
- Preserved migration-sensitive app IDs, data paths, repository names, and integration protocol identifiers so existing installations retain settings, memory, and integrations.
- Includes GitHub device-flow connection, guarded plan approval, and the current client-brain/MCP improvements.

## macOS artifact

The Apple Silicon DMG is named `r3to.os-6.5.3-arm64.dmg`. Local unsigned builds are for testing and require right-clicking the app and choosing **Open**; public distribution should use Developer ID signing and Apple notarization.
